# 月度订阅配置文档

本文档用于在 App Store Connect 中配置月度订阅产品。已根据应用的 Bundle ID（`eth.hyh.batchfilerenameassistant`）和 App 名称（`Batch File Rename Assistant`）填写基本信息，部分字段仍需根据实际情况确认。

## 基本信息

### 参考名称

参考名称将用于 App Store Connect 以及"销售和趋势"报告中，不会显示在 App Store 上。名称不得超过 64 个字符。

**参考名称：** `Batch File Rename Assistant 月度订阅`

### 产品 ID

用于报告的唯一字母数字 ID。一旦你将产品 ID 用于某产品，即使删除该产品，此产品 ID 也无法再次使用。

**产品 ID：** `eth.hyh.batchfilerenameassistant.monthly`

**注意事项：**

- 产品 ID 必须唯一，建议使用反向域名格式
- 产品 ID 一旦创建并保存，即使删除产品也无法再次使用
- 建议使用小写字母、数字、下划线和连字符

## 订阅组配置

### 订阅组名称

订阅组用于将相关的订阅产品组织在一起。如果这是第一个订阅产品，需要创建新的订阅组。

**订阅组名称：** `Batch File Rename Assistant 订阅`

**订阅组参考名称：** `Batch File Rename Assistant Subscription Group`
