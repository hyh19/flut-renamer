# Google Play Console 内容 - 加泰罗尼亚文版本

## 应用名称（最多 30 个字符）

Canvi de Nom d'Arxius

## 简短说明（最多 80 个字符）

Canvi de nom d'arxius per lots amb inserció, substitució, eliminació i AI.

## 完整说明（最多 4000 个字符）

Canvi de Nom d'Arxius és una eina potent i fàcil d'utilitzar per al canvi de nom d'arxius per lots, dissenyada per ajudar-vos a gestionar i canviar el nom dels arxius de manera eficient.

**Característiques principals：**

• **Canvi de nom per lots**：Canvieu el nom de diversos arxius alhora, eliminant la necessitat de canviar el nom dels arxius un per un manualment.

• **Múltiples opcions de canvi de nom**：

    - Inserció de text：Afegiu text personalitzat en posicions especificades als noms d'arxiu
    - Substitució de text：Substituïu el text especificat als noms d'arxiu amb text nou
    - Eliminació de text：Elimineu el text especificat dels noms d'arxiu
    - Canvi de nom incremental：Afegiu automàticament números seqüencials als arxius, per exemple Arxiu-1, Arxiu-2, Arxiu-3

• **Canvi de nom intel·ligent basat en IA**：Utilitzeu tecnologia IA per generar automàticament regles de canvi de nom basades en la vostra descripció, fent que el canvi de nom d'arxius sigui més intel·ligent i convenient.

**Casos d'ús：**

- Organitzar arxius de fotos i vídeo
- Modificar per lots els noms d'arxius descarregats
- Estandaritzar convencions de nomenclatura d'arxius
- Afegir números seqüencials o dates als arxius
- Netejar caràcters innecessaris als noms d'arxiu

Canvi de Nom d'Arxius ofereix una interfície intuïtiva i operacions simples, fent que el canvi de nom d'arxius sigui fàcil i eficient。
