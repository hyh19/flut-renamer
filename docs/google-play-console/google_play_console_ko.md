# Google Play Console 内容 - 韩文版本

## 应用名称（最多 30 个字符）

파일 일괄 이름 변경

## 简短说明（最多 80 个字符）

삽입, 교체, 삭제, 순차 이름 변경 기능을 갖춘 강력한 일괄 파일 이름 변경 도구. AI 기반 스마트 이름 변경 기능으로 효율적인 파일 관리를 제공합니다.

## 完整说明（最多 4000 个字符）

파일 일괄 이름 변경은 파일을 효율적으로 관리하고 이름을 변경할 수 있도록 설계된 강력하고 사용하기 쉬운 일괄 파일 이름 변경 도구입니다。

**주요 기능：**

• **일괄 이름 변경**：여러 파일을 한 번에 이름을 변경하여 파일을 하나씩 수동으로 이름을 변경하는 번거로움을 없앱니다。

• **다양한 이름 변경 옵션**：

    - 텍스트 삽입：파일명의 지정된 위치에 사용자 정의 텍스트 삽입
    - 텍스트 교체：파일명의 지정된 텍스트를 새 텍스트로 교체
    - 텍스트 삭제：파일명에서 지정된 텍스트 삭제
    - 순차 이름 변경：파일에 자동으로 순차 번호 추가（예：파일-1、파일-2、파일-3）

• **AI 기반 스마트 이름 변경**：AI 기술을 사용하여 설명에 따라 이름 변경 규칙을 자동으로 생성하여 파일 이름 변경을 더욱 스마트하고 편리하게 만듭니다。

**사용 사례：**

- 사진 및 동영상 파일 정리
- 다운로드한 파일명 일괄 수정
- 파일 명명 규칙 표준화
- 파일에 순차 번호 또는 날짜 추가
- 파일명의 불필요한 문자 정리

파일 일괄 이름 변경은 직관적인 인터페이스와 간단한 작업으로 파일 이름 변경을 쉽고 효율적으로 만듭니다。
