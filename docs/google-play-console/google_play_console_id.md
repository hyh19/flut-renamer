# Google Play Console 内容 - 印度尼西亚文版本

## 应用名称（最多 30 个字符）

Pengganti Nama File

## 简短说明（最多 80 个字符）

Pengganti nama file batch: sisipkan, ganti, hapus dan AI.

## 完整说明（最多 4000 个字符）

Pengganti Nama File adalah alat pengganti nama file batch yang kuat dan mudah digunakan, dirancang untuk membantu Anda mengelola dan mengganti nama file secara efisien.

**Fitur utama：**

• **Penggantian nama batch**：Ganti nama beberapa file sekaligus, menghilangkan kebutuhan untuk mengganti nama file satu per satu secara manual.

• **Berbagai opsi penggantian nama**：

    - Sisipkan teks：Tambahkan teks khusus di posisi yang ditentukan dalam nama file
    - Ganti teks：Ganti teks yang ditentukan dalam nama file dengan teks baru
    - Hapus teks：Hapus teks yang ditentukan dari nama file
    - Penggantian nama bertahap：Tambahkan secara otomatis nomor berurutan ke file, misalnya File-1, File-2, File-3

• **Penggantian nama pintar berbasis AI**：Gunakan teknologi AI untuk secara otomatis menghasilkan aturan penggantian nama berdasarkan deskripsi Anda, membuat penggantian nama file lebih pintar dan nyaman.

**Kasus penggunaan：**

- Mengatur file foto dan video
- Modifikasi batch nama file yang diunduh
- Standarisasi konvensi penamaan file
- Tambahkan nomor berurutan atau tanggal ke file
- Bersihkan karakter yang tidak perlu dalam nama file

Pengganti Nama File menawarkan antarmuka yang intuitif dan operasi sederhana, membuat penggantian nama file mudah dan efisien。
